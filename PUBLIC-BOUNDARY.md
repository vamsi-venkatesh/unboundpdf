# Public boundary

This is a selected-source publication, not the canonical UnboundPDF development repository.

## Included

- Three tool pages: Merge PDF, OCR PDF and Redaction Verifier.
- The first-party browser modules those pages need.
- A limited Workspace demonstration that merges selected documents and computes a receipt from the produced bytes.
- English OCR runtime data and the runtime files required to use it locally.
- Synthetic verification fixtures and compact tests.
- Product architecture, privacy, claims, limitations and third-party notices.

## Withheld

- The remaining production tools and the full PDF Editor.
- The complete production Workspace and Document Passport implementation.
- Compression, image-patching and advanced conversion internals outside the selected dependency set.
- SEO and content automation, keyword research, competitor captures and growth playbooks.
- Deployment configuration, host details, backups, Cloudflare configuration and release procedures.
- Analytics, Search Console data, review moderation services and user submissions.
- Credentials, tokens, environment files, session stores and local machine paths.
- Internal prompts, founder instructions, vault material, roadmaps and unpublished designs.
- The canonical repository history and internal QA archive.

The public export is built as a new history so deleted or superseded private material cannot survive in Git objects.
